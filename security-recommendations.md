# Security Recommendations

Based on the network scanning exercise, the following security practices are recommended.

## 1. Disable Unnecessary Services

Services that are not required should be disabled. This reduces the number of entry points available to an attacker.

## 2. Use a Firewall

A firewall should be configured to allow only necessary network connections.

Unnecessary inbound connections should be blocked.

## 3. Keep Software Updated

Operating systems and network services should be regularly updated to reduce the risk of known vulnerabilities being exploited.

## 4. Use Strong Authentication

Remote services should use strong passwords and, where possible, multi-factor authentication.

## 5. Restrict Remote Access

Remote access services should only be accessible to authorised users and trusted networks.

## 6. Monitor Network Activity

Network activity should be monitored for unusual connections, repeated failed login attempts, or unexpected services.

## 7. Perform Regular Security Scans

Regular network scans can help identify newly exposed services and changes to the system's attack surface.

## Conclusion

Good network security involves identifying exposed services, understanding their purpose, reducing unnecessary exposure, and continuously monitoring systems.

The recommendations in this project demonstrate basic defensive security practices that can be applied to networked systems.
